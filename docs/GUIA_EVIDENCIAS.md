# Evidencias documentadas

Las capturas reales de ejecución se integraron directamente en el documento final de entrega, por lo que no se almacenan imágenes dentro del repositorio.

El repositorio conserva únicamente los resultados escritos y verificables de las herramientas utilizadas:

- `evidencias/03-sonarqube-resultados.md`: resultado aprobado de SonarQube Cloud.
- `evidencias/04-docker-resultados.md`: construcción, ejecución y comprobación del contenedor.
- `evidencias/05-trivy-resultados.md`: comparación del escaneo inicial y final de Trivy.
- `docs/INFORME_ENTREGA.md`: enlaces, interpretación de resultados y reflexión final.

Los archivos anteriores corresponden a las ejecuciones reales realizadas durante la actividad.
